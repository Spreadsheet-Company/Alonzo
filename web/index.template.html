Alonzo: the engine's loop and the viewport

A cartridge running on the host's loop: every input is a cell the host writes, every effect a cell it reads, and the Screen's cells are drawn as one byte each through the Palette. Below it, a window of a sheet drawn from the view record alone, the lines frazaro view prints, every cell where the record puts it. Nothing on this page leaves it: it reads nothing from the network and writes nothing anywhere.

The engine · the host's loop over the module, the Life cartridge

    The cartridge

    The file the host loads, cartridges/life/life.vla. Edit it and press Load the cartridge: change (rate 30) to (rate 0) and the loop has no tick, one step for each edit. The engine's module reads it whole, the manifest and every row, and the language computes each cell; the fake module, when no engine is built in, reads the manifest alone and draws its declared tiles whatever the rows say.

    Click the plane to give it the keys: the arrows, Z, X, A, S, Enter and Space are player 1's.

    Paste a record

    A view record of your own, the lines frazaro view <program> --sheet <name> prints: it is read here, drawn, and never saved. An unknown row is counted and the status line says how many.

    How the viewport reads the record
    • sheet rows are the tabs; a hidden or very-hidden sheet shows under the tabs' toggle. A tab without a record asks the host for one: here, the fixture of the same program if there is one.
    • window is the record's scope, the scroll's extent, never less than a screen; extent is the sheet's used rectangle; gridlines on or off.
    • column rows give widths in characters, the file's own unit, turned into pixels by ECMA-376's rule (72 is 504 px, 60 is 420 px; a column without a row is 64 px, Excel's default); a hidden column is skipped; a column's format fills its empty cells.
    • format rows give a fill, general or text, wrap or nowrap. cell rows show their value as the reader spells it, numbers right, text left, TRUE and FALSE and errors centred; formula rows show the formula's text, in green, until the value row lands (KERNEL.7). A nowrap text spills into empty neighbours to the right; a number never does.
    • style and sentence rows ride on their cell: the sentence's row is in the selection's line below the grid, and in the select event the first game's chrome reads.
