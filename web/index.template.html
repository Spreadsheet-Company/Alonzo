The log

    The sheets

    Any sheet of the grid, live: a tab shows it, and every frame and every scroll views it again through the cells in view; the previous frame's twins are among the hidden sheets.

    The source and the cartridge

    The source, none: an empty sheet has no source, is what a person writes: the cartridge's manifest, then its rows written short by template macros, a palette one call and a pattern one picture, a string a row of it, from the library the source includes, below. Build the cartridge runs the pass in the page, the module's alonzo_expand, the function cargo run --release --example expand runs, to the same bytes, and puts the cartridge it writes in the second box, to be read before Load loads it: the pass loads nothing, and a cartridge running goes on running (docs/SPEC.md section 7.8). The fake module holds no pass, and says so.

    The cartridge, none: the empty sheet is the page's own, the file the host loads, picked in the bar or pasted here.

    Paste another cartridge, edit this one, or build it again from its source, and press Load: change (rate 30) to (rate 0) and the loop has no tick, one step for each edit. The engine's module reads it whole, the manifest and every row, and the language computes each cell; the fake module, when no engine is built in, reads the manifest alone and draws its declared tiles whatever the rows say.

    The libraries the sources include

    Template macros, the author's and never the engine's: change one, or write one of your own in a source, and build again. Build hands the pass every library the page holds, as edited here.

    The replay

    A replay, none: this cartridge has no replay of its own, is every write a run made between its steps: a header naming the cartridge by the SHA-256 of its text and the seed, then each frame as one form holding its rows, (frame 12 (cell "Input" "B5" 1)), the Input sheet's cells that changed and each person's edit that landed; the host's derived writes are never logged, a replay re-deriving them (docs/SPEC.md section 7.6). Paste one here and press Play the replay: the host loads the cartridge again with the replay's seed and plays its frames at the cartridge's rate, a person's edits waiting until it ends, and pauses at its last frame; Run then carries on with the live inputs. Copy the replay puts what the host has recorded since the last load on the clipboard and in this box, a replay played among it, so a replay played and copied is the replay played. The input card's and the sound card's own replays are the loop oracle's runs of them: play the sound card's with the sound on and hear the run again, its ticks, the knob turned to a word that is no wave and back, and a stretch at a third of the speed. Kairos's is the owner's two games: the major prize won, the minor refused on the way, then a fall at the last level.

    Paste a record

    A view record of your own, the lines frazaro view <program> --sheet <name> prints: it is read here, drawn, and never saved. An unknown row is counted and the status line says how many.

    How the viewport reads the record
    • sheet rows are the tabs; a hidden or very-hidden sheet shows under the tabs' toggle. A tab without a record asks the host for one: here, the fixture of the same program if there is one.
    • window is the record's scope, the scroll's extent, never less than a screen; extent is the sheet's used rectangle; gridlines on or off.
    • column rows give widths in characters, the file's own unit, turned into pixels by ECMA-376's rule (72 is 504 px, 60 is 420 px; a column without a row is 64 px, Excel's default); a hidden column is skipped; a column's format fills its empty cells.
    • format rows give a fill, general or text, wrap or nowrap. cell rows show their value as the reader spells it, numbers right, text left, TRUE and FALSE and errors centered; formula rows show the formula's text, in green, until the value row lands (KERNEL.7). A nowrap text spills into empty neighbors to the right; a number never does, and a number too wide for its column draws #s across it, as Excel fills a cell under a fixed number format (ENGINE.14).
    • style and sentence rows ride on their cell: the sentence's row is in the selection's line below the grid, and in the select event the first game's chrome reads.
